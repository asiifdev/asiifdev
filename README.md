## How I approach engineering

1. Understand the business process and where work gets stuck.
2. Agree on scope, constraints, and a practical definition of success.
3. Choose the simplest technology that solves the problem; AI is not the default answer.
4. Build and test against real workflows, with explicit human hand-off for risky actions.
5. Deploy with documentation and a maintainable handover.
